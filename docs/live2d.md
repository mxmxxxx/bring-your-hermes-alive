# 专属 Live2D 角色

初始设计方向：银白长发、蓝眼睛、猫耳、宽松白 Tee，温柔而略带调侃。
此描述可替换，部署工具不依赖某个角色。

AI 概念图不等于可运行模型。制作流程：确认设定 → 分层绘画与遮挡补画 →
Cubism 绑定 → 导出运行文件 → 在上游客户端配置并验收。

第一版建议：眨眼、嘴型、呼吸、轻微头部转动、发丝摆动，外加温柔/调侃/思考表情。
通常需要 `.model3.json`、`.moc3`、纹理以及模型引用的 physics、expression、motion
文件；以导出模型实际引用和上游加载要求为准。只提供 PSD 也还不能直接运行。

按上游 `model_dict.json` 及模型安装文档配置路径。确认表情名与角色提示词一致。
不要承诺 PNG 自动一键转为有质量的 Live2D 绑定。

仓库不打包第三方模型、Live2D SDK 或生成概念图。贡献角色前明确素材来源、分发许可、
修改许可、商业使用条件及署名要求；软件 MIT 许可不替代角色和 SDK 许可。
